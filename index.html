Casrion Download

A notes app that does the writing‑down part for you.

Here is the thing I could never fix about taking notes. The moment worth keeping and the moment you have time to write it down are never the same moment. You are four paragraphs into something good, you hit a line you want, and the only way to keep it is to leave. Open the app. Find the right file. Paste. Fix the formatting it dragged in. Type out where it came from. By then you have lost the thread you were pulling, and after two or three of those you quietly stop keeping anything at all.

So Casrion puts that entire detour on one key. You copy the line, you press the key, you keep reading. The note is already written by the time you look up from the page.

Which is easier to show than explain, so this page does it too. Select any sentence here. A little tag will show up next to it. Click the tag.

One honest note: in the app the key is Ctrl+Shift+C, but your browser has already claimed that one for its developer tools and will not give it back, so on this page you click the tag instead. The headings and undo below do work on the real keys.

It writes it down properly, not just quickly

A capture that lands as a wall of unformatted text is barely better than the clipboard. So the key you press decides the shape it arrives in. Grab a definition as a heading, a snippet as a fenced code block, the one line that actually mattered in bold. It is plain Markdown on the other side, in a file you chose, on a disk you own.

It remembers where you got it

A quote with no source is half a note. You will read it back in November and have no idea whether you agreed with it or were arguing with it. So every capture can carry a small stamp: the page it came from, the app it was in, the time you took it. Look at the notebook next to this text and you will see the stamps piling up under everything you kept.

It is one toggle, and it is off if you want it off. There is a checkbox on the notebook. Turn it off and watch the stamps go.

When you have no idea what you are looking at

Sometimes the problem is not keeping the sentence, it is that the sentence means nothing to you yet. Select it, tap Ctrl twice, and a small window explains it where you are standing, in whatever app you are standing in. It reads the window around your selection too, so it knows a stray symbol is part of the formula three lines up.

That runs on a language model living on your own disk. Nothing is sent anywhere. It is a one time download of about a gigabyte, and it stays out of your way until you ask: it does not load at launch, it loads the first time you look like you are about to need it, and it hands the memory back about five minutes after you stop. Idle, the whole app sits under 450 MB.

When the thought is your own

Not everything worth keeping is something you copied. For the ones that start in your own head, a small writer floats over whatever you are doing, takes the thought, and vanishes. Markdown works while you type it. If you get interrupted halfway, and you will, the draft is still sitting there when you come back.

Or say it out loud

Some thoughts come out faster than you can type them, and the typing kills them on the way. Hold the key, say it, let go. The recording tucks itself into the note next to everything else, and it is a normal audio file in a normal folder, so it will still play in ten years when this app is long gone.

Nothing leaves your machine

This is not a privacy policy, it is an architecture. Casrion makes no network requests. Not fewer than most, none. There is no account to make, no sync server it is quietly reaching, no analytics counting your keypresses. Your notes are Markdown files in folders you picked, and if you delete the app tomorrow every one of them is still readable in Notepad.

The Windows installer is unsigned, because the certificate costs more than this app makes, so SmartScreen will put up a blue box the first time. Click More info, then Run anyway. Once, and never again. The Mac build needs a few permissions, which are all below.

Mac needs about two minutes of setup

Apple wants money for a signature too, so macOS treats Casrion as a stranger the first time. Here is the whole thing, in order, and then it is done forever.

  1. Install it

    Open the .dmg and drag Casrion into Applications.

  2. Open it the first time

    Because it is not from the App Store, the first launch gets blocked. In Applications, right click Casrion and choose Open, then Open again in the dialog. If it still refuses and says it cannot be opened, paste this into Terminal once and then open it normally:

    xattr -cr /Applications/Casrion.app

  3. Allow Accessibility, for Explain

    Explain has to read the text you highlighted. Go to System Settings → Privacy & Security → Accessibility and switch Casrion on. Casrion opens that pane for you the first time you try to explain something.

  4. Allow Input Monitoring, for the double tap

    macOS guards raw key taps separately from everything else, so if you want the double tap of Cmd to work, switch Casrion on under Input Monitoring as well. Do not want to? Skip it. Cmd+Shift+E only needs the step above.

  5. Allow the microphone, for voice memos

    macOS asks the first time you record. Click Allow.

  6. Say yes to the browser question, for source stamps

    The first capture out of Safari or Chrome makes macOS ask whether Casrion can control the browser. That question is how your notes get stamped with the exact page. Say no and captures still note which app they came from, just without the address.

  7. Quit and reopen once

    macOS only applies those switches to a fresh launch. Quit Casrion properly from the menu bar icon and open it again. Setup only, never again.

Questions people actually ask

Windows says it protected my PC. Is that bad?
No. That is SmartScreen, and it appears for any installer without an expensive code signing certificate. It does not mean something was found. More info, then Run anyway.
Where do my notes actually live?
In Markdown files, in folders you pick. Screenshots and voice memos sit in an assets folder right beside each note. Move them, back them up, put them in Dropbox, open them in something else. They are just files.
Does it need internet?
Never. The one exception is the optional Explain model, which is a single download the first time you turn it on, and after that even that works on a plane.
How much memory does it use?
Around 450 MB sitting idle. If you use Explain it climbs while the model is loaded and drops back about five minutes after you stop asking things.
How do I quit it, or update it?
Closing the window leaves it capturing from the tray, which is the point. To really quit, right click the tray icon and choose Quit. To update, download the newer installer and run it over the old one. Your notes are never touched.
Do I need an account?
No. There is nothing to sign up for. There is no server to sign up to.
My Mac says Casrion cannot be opened.
That is macOS being careful about an unsigned app, not a problem with the app. Right click it in Applications and choose Open, then Open again. If it still refuses, run xattr -cr /Applications/Casrion.app in Terminal once. Full walkthrough is up in the Mac setup.
Which Macs?
Apple Silicon, M1 and newer, on macOS 11 or later. Intel Macs are not supported yet.
I updated on Mac and a permission stopped working.
macOS ties permissions to the exact copy of the app, so replacing Casrion with a new version can quietly invalidate the checkmarks while they still look switched on. In Privacy & Security, open Accessibility and Input Monitoring, remove Casrion with −, add it back with +, then quit and reopen.
The download did not start.
Press the button again, it always points at the current version. If your browser is being strange, right click and choose Save link as. Still stuck, mail me at hello@casrion.com.
